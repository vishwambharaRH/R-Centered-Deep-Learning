# Supplementary Materials

Reserved for supplementary materials accompanying the ICBBE 2026 submission
(e.g. an extended results appendix), if/when provided separately from the
manuscript. The full reproducibility layer that would otherwise pad the paper
lives in this repository's `data/`, `configs/`, `src/`, and `results/`
directories instead — see the root `README.md`'s Reproducibility Checklist.
