# ⁠ configs/ ⁠ is VERY important

This is one of the best things you can do for reproducibility.

Instead of having parameters scattered across Python files, make the experiments declarative.

For example:

⁠ yaml
experiment: A2

sampling_rate: 250

window:
  pre_r: 120
  post_r: 320

model:
  conv1_filters: 32
  conv1_kernel: 7
  conv2_filters: 64
  conv2_kernel: 5
  bilstm_hidden: 128
  dropout: 0.3

training:
  optimizer: Adam
  learning_rate: 0.001
  epochs: 15
  seeds:
    - 1
    - 2
    - 3

loss:
  type: focal
  gamma: ...
  alpha: ...

dataset:
  train: qtdb_train
  validation: qtdb_validation
  test: ludb_test
 ⁠

Then A0–A4 become extremely transparent.

It also lets you answer the reviewer's request for:

	⁠CNN/BiLSTM layers, kernel sizes, hidden dimensions, dropout, optimizer, learning rate, batch size, stopping criterion, focal-loss parameters, random seeds and model-selection procedure.
